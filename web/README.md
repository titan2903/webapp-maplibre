# WebGIS MapLibre Frontend

A WebGIS application built with Vite, TypeScript, and MapLibre GL JS.

## Deployments & CI/CD

- **Frontend (Netlify)**: [https://steady-cactus-539fb1.netlify.app](https://steady-cactus-539fb1.netlify.app)
- **Backend Spatial Engine (Heroku)**: `https://webapp-maplibre-spatial-engine-35d9f0049989.herokuapp.com`

Automated deployment is configured via GitHub Actions (`.github/workflows/deploy-web-netlify.yml`).
